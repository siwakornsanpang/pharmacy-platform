# pharmacy-web

เว็บสาธารณะและโซนสมาชิกของ Pharmacy platform รันจากโมโนเรโป ไม่ใช่ repo แยก

วิธีติดตั้งและตัวแปรสภาพแวดล้อมอยู่ที่ [README ของราก repo](../../README.md)

หน้าสมาชิกที่ต้องล็อกอินถูกกันที่ `middleware.ts` ล็อกอินสมาชิกบนเครื่องพัฒนาเป็นบัญชีจำลอง รายละเอียดอยู่ใน [known limitations](../../docs/verification/known-limitations.md)
